# tools/iso/packages.txt — כל חבילת apt שה-ISO חייב לשאת (#1139).
#
# זה **האיחוד** של ארבע רשימות שחיות בקבצים אחרים, ואף אחת מהן אינה
# מועתקת לכאן ביד: ‏tests/test_iso_build.py קורא את המקורות עצמם ונופל
# אם חבילה נוספה שם ולא כאן (או להפך). הלקח של R25: ההתקנה offline
# נכשלת על החבילה הראשונה שחסרה ב-pool, ואיש לא יגלה זאת עד מול שרת
# אמיתי בלי אינטרנט.
#
# מקורות (אותו שם בדיוק, כמו ב-apt):
#   [installer]  PKGS=(...)              deploy/setup-boot-server.sh
#   [initramfs]  apt-get install ...     tools/build_initramfs.sh (הבסיס)
#   [gui]        GUI_PACKAGES=(...)      tools/build_initramfs.sh (--with-gui)
#   [gui-build]  make pkg-config *-dev   tools/build_initramfs.sh (--with-gui)
#   [toolbox]    TOOL_PKG=(...)          tools/build_initramfs.sh (--tools-selection)
#   [vmupdate]   שורה לחבילה             deploy/vmupdate-packages.txt (#1334)
#   [iso]        מה שרק ה-ISO מוסיף — ראה הסבר ליד כל אחת
#
# שורה = חבילה אחת. `#` פותח הערה. ‏make-pool.sh מוריד את כולן **עם
# התלויות**; ‏installer/lib/bootstrap.sh מתקין אותן.
#
# **כל ההתקנות הן `--no-install-recommends`** (‏#1987; ‏tests/
# test_no_install_recommends_1987.py נופל על התקנה בלעדיו). תלות שהשרת
# באמת צריך ואינה Depends של אף חבילה כאן — נרשמת כאן במפורש, עם הסיבה.
# ‏fonts-ibm-plex יושבת ב-**contrib** (#120) — ה-pool כולל main+contrib.

# שכבה 2: החלטות

שלושה סוגים: **D** קיימות בקוד היום (39), **B** החלטות שמוח כזה יכול לקבל (רק אלה שהומלצו ✅ או ⏳),
ו-**K1–K10**, הכללים המתוכננים מטיוטת התכנון.

**איך קוראים את עמודת "איפה":** ‏`קובץ:שורה` · ‏`סימבול`. **הסימבול הוא המצביע, והשורה היא רמז בלבד**
(נכונה ל-`cf58981a`). ‏«טקסט» בסוגריים הוא עוגן: מחרוזת שמופיעה באותו קובץ, ליד הכלל, כשהסימבול
הוא פונקציה גדולה (למשל `_send` ב-`chunksend.py`). בפריט שעוד לא קיים, המיקום הוא המקום שבו הנתון
הגולמי כבר יושב, או שבו המלאי מציע להוסיף אותו.

**הערה 1, הקצב 242m (השערה מהקוד, לא מדידה).** השולח מאט לפי שני קצבים, והאיטי קובע. ‏`--write-kbps`
(D7) הוא האיטי מבין תוצאות בדיקת הכתיבה × 0.9. ב-SSD של המעבדה: ‏179 × 0.9 ÷ 4.19MB ≈ ‏38 חתיכות
בשנייה, ונמדדו 36.1. ‏`record_wave` רושם את הדיסק כ"מגביל" (D4), ואחרי שני גלים `_limit_of` מוריד
ל-33.7MB/s × 8 × 0.9 ≈ ‏242m. כלומר לולאה. **מה יכריע: M13.** עד אז לא נוגעים ב-D4 וב-D7 (G8).

**הערה 2, room_714f980d (PR #3112, ‏13/11).** המשכפל השלים מגירה שחזרה בתוך המחיצה (S45, בלי
דיווח), ולא אמר `listening` על מחיצה 4. אחרי 780 ש' (D16, ‏T40) ‏`_send` הכשיל את **כל הגל**, ומגירה
תקינה ב-96% נמחקה. המשכפל המשיך לשלוח progress, ולכן **לא** סומן `lost` (D21). ההודעה ביומן אמרה
180 בטעות (L6).
